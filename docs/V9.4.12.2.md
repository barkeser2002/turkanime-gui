# TürkAnime İndirici v9.4.12.2 Release Notes

## Genel Bakış
v9.4.12.2, yepyeni bir **Simple GUI** modu, **Tranimaci** kaynak desteği, **multi-dil arama**, **fuzzy %95 eşleştirme popup'ı**, **universal bölüm parser'ı** ve port **34665** üzerinde tamamen yeniden yazılan **HTTP API sunucusu** getirir. Önceki sürümde rapor edilen birkaç kritik runtime hatası da düzeltildi.

## Sürüm Bilgileri
- **Sürüm**: 9.4.12.2
- **Tarih**: 22 Mayıs 2026
- **Tip**: Majör Feature Release
- **Önceki Sürüm**: 9.4.9.3

## ✨ Yeni Özellikler ve İyileştirmeler

### 🆕 Simple GUI (`turkanime-simple`)
- Mevcut `main.py` arayüzü hiç bozulmadan, yanında çalışan **paralel modern bir görünüm** (`turkanime_api/gui/simple/`).
- 3 kolonlu temiz layout: **Kaynaklar | Sonuçlar | Bölümler** + üst arama bar + canlı statusbar.
- Yeni script entry-point: `turkanime-simple` (pyproject.scripts).
- Kapsanan kaynaklar (6 tanesi de aktif): **TürkAnime**, AnimeciX, Anizle, TRAnimeİzle, OpenAnime, Tranimaci.
- **mpv embed:** "İzle" butonu artık `webbrowser` açmaz — TürkAnime için `Bolum.best_video().oynat()`, diğer kaynaklar için `AdapterBolum + stream_provider` üzerinden direkt mpv başlatır. PyInstaller'da `bin/mpv.exe` otomatik PATH'e eklenir.

### 🆕 Tranimaci.com Kaynağı
- Yeni source adapter (`turkanime_api/sources/tranimaci.py`).
- Site'in özel **SHA-256 proof-of-work WAF**'ı Python tarafında çözülür (~0.05s) — `__waf_session` cookie 30 dk session'da kalır.
- Multi-CDN fallback: aynı bölüm için 10 farklı CDN replikası, quality başına sırayla denenir (1080p / 720p / 480p).
- Hem CLI hem GUI hem yeni HTTP API üzerinde tam entegre.

### 🆕 Universal Episode Parser
- `turkanime_api/common/episode_parser.py` — kaynaklar arası bölüm başlığı normalizasyonu.
- Desteklenen permutasyonlar: `S01E02`, `s1e2`, `1x02`, `B01S02` / `b1s2` (Türkçe Bölüm/Sezon), `S02B05`, `Sezon 1 Bölüm 2`, `Episode 13 Season 2`, `12. Bölüm`, `Ep. 8`, `E12`, `01_02`, çıplak sayı, OVA / Movie / Special / Final etiketleri.
- Her sonuç `EpisodeInfo(season, episode, label, title, score, normalized())` döndürür — `S01E02` kanonik formunda.
- **27/27 birim test geçti.** API'nin `/{source}/episodes/{slug}` endpoint'i bu metadata'yı her bölüme otomatik ekler ve season+episode'a göre sıralar.

### 🆕 Multi-Dil Arama + %95 Fuzzy Popup
- `turkanime_api/common/title_match.py`:
  - **AniList GraphQL + Jikan v4**'ten romaji / english / native / synonyms title varyantları çekilir, **1 hafta cache**'lenir (`~/.turkanime/title_cache/`).
  - `multilang_search(searcher, q)` — tüm dilleri sırayla dener, sonuçları benzersizleştirip skorlar.
  - `fuzzy_score`: rapidfuzz `token_set_ratio` + `partial_ratio` + `ratio` max (yoksa SequenceMatcher).
- **%95 eşik:** Tam eşleşme (≥0.95) → otomatik kullanılır. Altı (≥0.55) → kullanıcıya popup:
  - `turkanime_api/gui/match_popup.py` — CTk modal, skor rozeti yeşil/amber/kırmızı, "Seç" / "İptal".
  - Simple GUI'de aktif kaynakta exact yoksa otomatik açılır.
- Canlı doğrulama: `"attack on titan"` sorgusu → AniList'ten `Shingeki no Kyojin` alias'ı çekildi → animecix'te 8 exact + 6 possible bulundu, hepsi 1.000 skor.

### 🆕 TurkAnime API Server v2 (`turkanime_server/`)
- **Port `34665`** (env `PORT` ile override edilebilir).
- Tüm 5 web kaynağı tek API arkasında: animecix, anizle, tranime, openani, tranimaci.
- Yeni unified endpoint'ler:
  - `GET /health`              — feature toggle + source listesi
  - `GET /sources`             — yetenek matrisi (search/episodes/streams)
  - `GET /search?q=&source=&fuzzy=true&threshold=0.95` — multi-dil universal arama
  - `GET /{source}/search?q=`
  - `GET /{source}/episodes/{slug}`   — universal parser metadata dahil
  - `GET /{source}/streams/{episode_slug}`
- MySQL şeması güncellendi — `anime_matches.aliases` (TEXT), `anime_matches.updated_at`, `user_episode_status.position_seconds` eklendi; tüm yazımlar `ON DUPLICATE KEY UPDATE` ile atomik upsert.
- **Dockerfile yenilendi:** Python 3.12-slim, multi-stage olmadan minimum runtime, chromium artık gerekli değil (curl_cffi yerine geçti). 34665 expose + healthcheck.
- **docker-compose.yml**: 34665 expose, env override (`DB_HOST`/`DB_USER`/`DB_PASSWORD`/`DB_NAME`).

### 🆕 OpenAnime Arama Yeniden Yazıldı
- openani.me'nin gerçek arama API'si (`api.openani.me`) **Vanguard auth** gerektirir ve dışarıdan erişilemez; `/explore?q=` ise server-side filtreleme yapmıyor (her sorgu için aynı 28 popüler animeyi döndürüyor).
- Yeni iki kademeli strateji:
  1. Sorgu slug varyantlarına çevrilip `/anime/<slug>` URL'leri doğrudan probe ediliyor (HTML SSR ile gelen slug ile sayfa doğrulanır).
  2. `/explore` popüler katalogdan client-side filtre.
- CFSession bağımlılığı kaldırıldı — FlareSolverr ile Chrome version mismatch çakışmasında patlamıyor artık. Yedek `_light_get` ile curl_cffi.

## 🐛 Düzeltilen Hatalar

### Kritik Runtime Hatalar
- ✅ **`main.py` 8 adet F821 buggu** (`gui/main.py:3086, 4229, 4415, 4488, 5196, 5255, 5295, 5312`): `except Exception:` bloklarındaki lambda'lar tanımsız `e` değişkenine referans veriyordu. Hata oluşunca `NameError` fırlatacaktı. `except Exception as e:` + `lambda e=e:` ile düzeltildi.
- ✅ **openani search misleading sonuçlar:** Eski adapter explore sayfasının ilk 20 statik kaydını sorgudan bağımsız döndürüyordu. Artık doğru sonuç veya boş döndürüyor.

### Kod Kalitesi
- ✅ Ruff toplam 129 → 66 hata; 53 otomatik düzeltildi, 8 gerçek bug + 1 mantık bugu el ile.
